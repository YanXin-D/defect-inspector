# Baseline v1 实验记录

## 原始实验（用户在本机运行）

- Windows；Python 3.12.10；RTX 5080，15.92 GiB。
- PyTorch 2.14.1+cu130；torchvision 0.29.1+cu130。
- MVTec AD bottle；209 张正常训练图排序后按 random.Random(42) 打乱。
- 42 张正常图校准，167 张建库；官方测试集 20 张正常、63 张缺陷完整保留。
- 整图缩放至 224×224，ImageNet mean/std，无中心裁剪。
- 冻结 ImageNet ResNet18 layer3，256×14×14；L2 归一化局部特征。
- 特征库 32732×256；最近欧氏距离的最大值作为图像分数。
- 正常验证分数线性插值 95% 分位数：0.3869686886668205；严格大于阈值判异常。
- 正常验证误报 3/42（7.14%）。

## 个案分析

唯一误报 test/good/006.png，分数 0.4749990403652191；低分正常对照
test/good/014.png，0.22889338433742523。
006 最大距离网格靠近瓶内中央，可见模糊斑纹；014 中央更均匀。
现象一致，但尚不能断定误报原因。黄圈只是网格中心，感受野重叠；
14×14 插值热力图没有像素级定位精度保证。

## 结论范围

单类别、小样本图像级结果；没有端到端训练，不是完整 PatchCore。
没有测量产线速度、跨类别泛化或像素级分割精度。
首次测试后已查看测试个案；后续据此修改算法需要额外独立评估数据。
